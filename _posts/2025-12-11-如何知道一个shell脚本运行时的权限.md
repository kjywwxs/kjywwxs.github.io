## 前言
工作中遇到了需求，需要检查我们所用脚本是否有可能有越权的风险，琢磨了一下，搞了下面这个来检查一些脚本的运行时权限~

## 完整整体流程
### STEP1 上传脚本，准备环境
将 audit_header.sh ，inject_audit.sh, watch_and_inject.sh上传到同一目录

```bash
pkill -f watch_and_inject.sh

sudo mkdir -p /var/log
sudo touch /var/log/script_audit.log
sudo chmod 666 /var/log/script_audit.log #确保所有用户都有权限写日志


yes|yum install dos2unix
dos2unix *.sh
chmod +x *.sh

```
### STEP2 执行注入

运行监听注入脚本
```
nohup bash watch_and_inject.sh > /var/log/watch_and_inject.log 2>&1 &
```
或者手动审计头注入(bin目录下和opt目录下所有shell脚本)
```bash
bash inject_audit.sh /bin
bash inject_audit.sh /opt
```

### STEP3 看日志
```bash
tail -f /var/log/watch_and_inject.log
```
```bash
tail -f /var/log/script_audit.log
```



## 审计脚本
audit_header.sh

```bash
#!/bin/bash

LOG_FILE="/var/log/script_audit.log"
TIMESTAMP=$(date '+%Y-%m-%dT%H:%M:%S')

# 调用链深度
DEPTH=${#BASH_SOURCE[@]}

# 入口脚本（用户实际运行的脚本）
ENTRY_SCRIPT="${BASH_SOURCE[-1]}"
ENTRY_REALPATH=$(readlink -f "$ENTRY_SCRIPT")

# 当前脚本（被 source 或执行的脚本）
CURRENT_SCRIPT="${BASH_SOURCE[0]}"
CURRENT_REALPATH=$(readlink -f "$CURRENT_SCRIPT")

# 调用它的上一层脚本（如果有）
if (( DEPTH > 1 )); then
    CALLER_SCRIPT="${BASH_SOURCE[1]}"
    CALLER_REALPATH=$(readlink -f "$CALLER_SCRIPT")
else
    CALLER_SCRIPT=""
    CALLER_REALPATH=""
fi

# 用户身份信息
USER_NAME=$(whoami)
UID_NUM=$(id -u)
GROUPS_LIST=$(id -Gn | tr ' ' ',')

# 如果当前脚本不是入口脚本 → 说明它是被 source 的
ROLE=$(
    if [[ "$CURRENT_REALPATH" == "$ENTRY_REALPATH" ]]; then
        echo "entry"
    else
        echo "sourced"
    fi
)

echo "timestamp=$TIMESTAMP role=$ROLE entry=$ENTRY_REALPATH current=$CURRENT_REALPATH caller=$CALLER_REALPATH depth=$DEPTH user=$USER_NAME uid=$UID_NUM groups=$GROUPS_LIST" >> "$LOG_FILE"

```

## 审计头注入脚本

指定目录下递归插入审计头

inject_audit.sh
```bash
#!/bin/bash

# 用法： ./inject_audit.sh /opt
#       ./inject_audit.sh ./scripts

TARGET_DIR="$1"
AUDIT_HEADER="/opt/audit_header.sh"
AUDIT_LINE="source $AUDIT_HEADER"

# 参数检查
if [[ -z "$TARGET_DIR" ]]; then
    echo "用法: $0 <目标目录路径>"
    exit 1
fi

# 目录存在检查
if [[ ! -d "$TARGET_DIR" ]]; then
    echo "错误: 目录不存在 -> $TARGET_DIR"
    exit 1
fi

# 将路径统一转换为绝对路径（关键！！！）
TARGET_DIR=$(realpath "$TARGET_DIR")
AUDIT_HEADER_REAL=$(realpath "$AUDIT_HEADER")

echo "处理目录：$TARGET_DIR"
echo "审计脚本：$AUDIT_HEADER_REAL"
echo ""

# 遍历所有 .sh 文件
find "$TARGET_DIR" -type f -name "*.sh" | while read file; do
    FILE_REAL=$(realpath "$file")

    # 跳过审计脚本自身
    if [[ "$FILE_REAL" == "$AUDIT_HEADER_REAL" ]]; then
        echo "[SKIP] 跳过审计脚本自身: $FILE_REAL"
        continue
    fi

    # 跳过已注入的脚本
    if grep -q "$AUDIT_LINE" "$FILE_REAL"; then
        echo "[SKIP] 已注入: $FILE_REAL"
        continue
    fi

    # 处理脚本头部
    if head -n 1 "$FILE_REAL" | grep -qE "^#!/"; then
        sed -i "1a $AUDIT_LINE" "$FILE_REAL"
    else
        sed -i "1i $AUDIT_LINE" "$FILE_REAL"
    fi

    echo "[OK] 已注入: $FILE_REAL"
done

echo ""
echo "递归处理完成。"

```

## 监听指定目录，自动注入审计头脚本
watch_and_inject.sh
```bash
#!/bin/bash
# 需要监听的多个目录（用空格分隔）
WATCH_DIRS=(
    "/opt"
    "/bin"
)

DELAY=60
INTERVAL=2   # 每2秒检测一次

declare -A HASH_MAP
TIMER_PID=""

stop_timer() {
    if [[ -n "$TIMER_PID" ]] && kill -0 "$TIMER_PID" 2>/dev/null; then
        kill "$TIMER_PID"
    fi
}

start_timer() {
    stop_timer
    (
        sleep "$DELAY"
        echo "[$(date '+%F %T')] 执行注入..."
        for DIR in "${WATCH_DIRS[@]}"; do
            bash inject_audit.sh "$DIR"
        done
    ) &
    TIMER_PID=$!
}

echo "开始轮询方式监听 *.sh 文件变化 (interval=${INTERVAL}s, delay=${DELAY}s)"

while true; do
    for DIR in "${WATCH_DIRS[@]}"; do
        for FILE in "$DIR"/*.sh; do
            [[ ! -e "$FILE" ]] && continue

            NEW_HASH=$(md5sum "$FILE" | awk '{print $1}')
            OLD_HASH=${HASH_MAP["$FILE"]}

            if [[ "$NEW_HASH" != "$OLD_HASH" ]]; then
                HASH_MAP["$FILE"]=$NEW_HASH
                echo "[$(date '+%F %T')] 检测到变化: $FILE"
                start_timer
            fi
        done
    done

    sleep "$INTERVAL"
done

```
